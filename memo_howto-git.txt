ローカルで追加／修正内容を確認する場合は、以下を実行し
hugo server -D # -D include content marked as draft
「localhost:1313」をブラウザで見る。

そして、以下を実行
mako@yourpc:~/gathering-apart-parts$ hugo
 ...
mako@yourpc:~/gathering-apart-parts$ git add .
mako@yourpc:~/gathering-apart-parts$ git commit -m "なにかコメント"
 ...
mako@yourpc:~/gathering-apart-parts$ git push
